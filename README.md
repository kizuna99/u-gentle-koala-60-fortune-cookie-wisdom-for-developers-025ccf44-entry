A single fortune-cookie line for a software developer, 112 characters.
`main.py` writes it to `/output/entry.txt`. The line was chosen from 18
candidates in a criteria-ordered tournament and refined over six measured
iterations: an old log line, written in anger at 3 a.m., will one day be
the lantern that leads a stranger out of an outage.
